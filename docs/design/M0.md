# M0 — Baseline and hygiene

Roadmap: `docs/roadmap/notebooklm-parity.md`.

## Scope

1. Make CI green under Node (the harnesses called `print()`, which Node lacks).
2. Make the README licence statement match `LICENSE` (GPL-3.0).
3. Pin the scope-gate invariants I1–I9 in `tests/test_invariants.py`.
4. Add `eval/` and record baseline numbers.

No behaviour changes to retrieval, the gate, or generation.

## Decisions

- **Print shim, not a harness rewrite.** The bundlers prepend
  `if (typeof print === "undefined") globalThis.print = ...`, so the same
  harness runs under Node and JavaScriptCore. CI now pins Node 20 explicitly
  rather than relying on the runner image.
- **Span labels, not chunk ids.** Retrieval relevance is "a top-k chunk
  contains this labelled span". Chunk ids change when M2 adds anchored
  chunking; spans do not, so the baseline stays comparable across milestones.
- **Two false-accept rates.** `gate_false_accept` counts every off-topic
  question that reaches the LLM (including `borderline`, which carries a
  verify-scope instruction). `gate_false_accept_confident` counts only
  off-topic questions ruled `in_scope`. The first is the upper bound; the
  second is what the gate alone lets through unguarded.
- **Offline injection resistance is structural.** With a stubbed LLM we can
  verify that off-topic probes cost zero calls and that injected text never
  enters the system prompt. Whether a real model obeys injected text is a
  `--live` measurement.
- **Citation metrics print n/a.** They need passage-marker citations (M4).

## Invariant test notes

- **I2** pins store-level isolation (separate data directories). Notebooks do
  not exist until M1, which must replace this with a per-notebook registry test.
- **I4**: a document lacking a key *does* satisfy a negated condition on that
  key (`docs/scoping.md`). That is deliberate and consistent with I4, because
  negation only ever removes documents. The test pins that adding any
  condition can only shrink the match set.

## Calibration change

The expanded gate set showed that `DENSE_RESCUE_FLOOR=0.25` no longer met its
own rule (sit above the off-topic dense maximum, now 0.356). The default moved
to 0.36: false accepts 0.250 -> 0.188, false refusals unchanged. This is the
one behaviour change in M0, justified by `scripts/measure_rescue.py` and
documented in `docs/scope-tuning.md`, as invariant I6 requires.

## Risks / gaps

- Datasets now meet the roadmap minimums, but every label was written by one
  author over six small corpora. Treat the absolute numbers as indicative and
  the deltas between milestones as the real signal.
- Offline injection checks are structural. Model obedience is a `--live`
  measurement and has not been run.
