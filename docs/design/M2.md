# M2 — Anchored ingestion and new source types

## Anchors without changing retrieval

The legacy `chunk_text` joins units with synthetic whitespace, so its output
cannot be located by substring search. A fresh span-based chunker was tried
first. It moved chunk boundaries and, measured on the eval, raised both gate
error rates (false accepts 0.188 to 0.237, false refusals 0.075 to 0.100). It
was rejected on the roadmap's safety-over-recall rule.

The shipped `chunk_spans` keeps `chunk_text`'s decisions and locates each
chunk in the original text by matching with whitespace ignored. Every unit is
a source substring and adjacent units are separated only by whitespace, so
each chunk maps to one contiguous span. The stored text is the source slice:
`text[start:end] == chunk`, with the same words, and therefore the same BM25
tokens. Every eval metric is unchanged. A hypothesis property test fuzzes the
round trip.

## Structured extraction

`extract_doc` returns `Extracted(text, pages, slides, segments, headings,
title)`; markers are character offsets into `text`. A chunk's page, slide and
section come from its start offset; its time range comes from the transcript
segments it overlaps.

## Source kinds

| Kind | How | Dependency |
|---|---|---|
| url | stdlib fetch, SSRF guard, stdlib HTML parser; trafilatura if installed | none / optional |
| youtube | youtube-transcript-api, merged into ~30 s segments | optional |
| text | pasted, stored as .txt | none |
| audio | faster-whisper, or OpenAI-compatible `/audio/transcriptions` | optional |
| image | pytesseract + Pillow | optional |
| pdf (scanned) | pdf2image + pytesseract when pypdf finds no text | optional |
| pptx, epub, html | stdlib zip/XML/HTML parsing | none |

Optional adapters are tested with fakes (`set_transcriber`,
`set_transcript_fetcher`, monkeypatched OCR and fetch). They have not been run
against the real libraries in CI.

## SSRF guard

The scheme must be http(s), and the port 80, 443 or above 1023. Every
resolved address must be public: loopback, RFC 1918, ULA, link-local
(including 169.254.169.254), multicast, reserved and unspecified addresses are
refused. Redirects are followed manually and re-checked. The body is capped
at 10 MB. Residual risk: DNS rebinding between the check and the connect.

## Guides and labels

The guide runs as a job after ingest. With an LLM: map-reduce (24k-character
windows), JSON via structured output, and the untrusted-data rule in every
prompt. Without one: an extractive fallback (salient prose sentences in
document order, frequent terms and phrases as topics, templated questions).
Citation markers are mapped to chunk ids, and markers pointing at no passage
are removed.

Labels: the extractive labeller reduces topics to plural-folded single terms
and labels each source with its most widely shared term. Tie-breaks are global
so related sources converge on one label. User-edited labels are preserved by
comparing against the last automatically applied label.
