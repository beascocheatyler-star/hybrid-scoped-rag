## Course description

An introduction to problem solving and programming using C++. Topics include
data types, control structures, functions, arrays, file I/O, and an introduction
to classes. Emphasis is on developing the discipline of writing correct,
readable, well-tested code.

## Learning outcomes

By the end of this course a student will be able to:

1. Decompose a problem statement into an algorithm.
2. Implement algorithms in C++ using appropriate control structures.
3. Write and call functions with parameters and return values.
4. Use one- and two-dimensional arrays to store and process collections.
5. Read from and write to text files.
6. Debug a program systematically using a debugger and test cases.

## Programming assignments

Assignments are posted on Canvas on Fridays and are due the **following Friday at
11:59 PM**. Submission is through the Canvas assignment page as a single `.cpp`
file named `lastname_firstname_hwN.cpp`.

Programs are graded on:

- **Correctness (70%)** — passes the provided and hidden test cases.
- **Style (20%)** — naming, indentation, decomposition into functions.
- **Documentation (10%)** — header comment block and inline comments explaining
  non-obvious logic.

**A program that does not compile receives a maximum of 40%.** Always compile a
fresh copy of your submission file before submitting it.

### Late work policy

Late assignments lose **10 percentage points per calendar day**, counted from the
due time. After **4 days** an assignment is no longer accepted and receives a
zero.

Each student has **three late days** for the semester that may be used to waive
the penalty, one day at a time. To use a late day, email the instructor **before**
the deadline stating which assignment and how many days. Late days cannot be
applied retroactively and cannot be used on the final project.

The **two lowest lab scores are dropped** automatically at the end of the
semester. There are no drops on programming assignments.

## Academic integrity

You may discuss *approaches* to assignments with classmates. You may not look at,
copy, or share assignment code. Submitting code you did not write — from a
classmate, a tutoring site, a previous semester, or a generative AI tool — is
academic dishonesty.

All submissions are run through automated similarity detection (MOSS). A first
violation results in a zero on the assignment and a report to the Dean of
Students. A second violation results in an F in the course.

**Use of AI coding assistants** (Copilot, ChatGPT, Claude, and similar) is
prohibited on programming assignments and exams. It is permitted for conceptual
questions — "explain how a while loop works" is fine, "write my homework 4" is
not. When in doubt, ask before you submit.
